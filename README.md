# Text_Classifier

This project builds a pipeline that extracts linguistic and semantic features from text and uses them in a powerful stacking ensemble classifier. It first defines multiple feature-extraction functions, capturing stylometric traits (e.g., word length, sentence length, punctuation use), repetition patterns, advanced discourse markers (e.g., hedging, pronouns, emotional words), and coherence metrics and applies them to the training, validation, and test data. The extracted features are then cleaned, selected with SelectKBest, and standardized. A stacking ensemble is trained with base models (RandomForestClassifier, XGBClassifier, and LGBMClassifier) and a logistic regression meta-model, combining their strengths. The model’s decision threshold is tuned to maximize F1-score on the validation set. Finally, the pipeline predicts labels on the test data and exports the results as stacking_ensemble_submission.csv, reporting accuracy, precision, recall, and prediction distribution.
